# 动态漫剧本写作规范详解（详细参考）

## 一、核心原则详解

### 视觉优先原则
动态漫以「静态画面 + 有限动态」为核心：
- 剧本需优先呈现「可视觉化内容」
- 避免大段心理描写
- 心理描写需转化为表情/动作

**错误示范：**
```
林澈心里很难过，他觉得自己被背叛了。
```

**正确示范：**
```
【林澈（眼眶泛红，嘴角下垂）：（无台词，微动态：手指轻颤）】
```

### 节奏适配原则
- 单集时长：3-5分钟（800-1200字）
- 每30秒需有「情绪拐点/动作亮点」
- 避免信息过载

### 成本可控原则
- 动态设计需标注「动态等级」（微/中/强）
- 强动态（如打斗、爆炸）单集不超过3处

### IP适配原则
- 改编类剧本需100%还原原作核心人设/剧情
- 原创类需保持人设前后一致、世界观自洽

## 二、结构框架

### 单集标准模板

| 模块 | 说明 |
|------|------|
| 场景头 | 每场景开头的统一格式 |
| 人物标注 | 首次完整/后续精简 |
| 动作描述 | 主体+动作+动态等级 |
| 台词 | 人物+情绪+口型适配 |
| 动态标注 | 微/中/强动态效果 |
| 音效/字幕 | 需要时标注 |

### 系列剧额外要求

| 要求 | 说明 |
|------|------|
| 小闭环 | 每3集形成「小闭环」 |
| 大节点 | 每10集推进「主线大节点」 |
| 配角标注 | 配角出场需标注「辨识度特征」（如：红发机车男→标注「红发+皮夹克+机车头盔」） |

## 三、格式规范详解

### 1. 页面设置

| 要素 | 要求 |
|------|------|
| 纸张 | A4 |
| 页边距 | 上下2.5cm、左右2cm |
| 中文字体 | 中文宋体（标题加粗） |
| 英文字体 | 英文/数字Arial |
| 标题字号 | 2号 |
| 正文字号 | 小4号 |
| 动态/音效字号 | 小5号 |
| 正文行距 | 1.5倍 |
| 段落间距 | 0.5倍 |

### 2. 场景头格式

**格式：** `【景别 - 地点 - 时间（光线条件）】`

| 要素 | 说明 |
|------|------|
| 景别 | 外景/内景 |
| 地点 | 具体地名 |
| 时间 | 白天/夜晚/凌晨等 |
| 光线条件 | 晨光/暗光/霓虹灯/月光/阳光斑驳等 |

**正确示例：**
```
【外景 - 临江大道 - 深夜（路灯暖光）】
【内景 - 办公室 - 下午（落地窗阳光）】
【外景 - 竹林深处 - 黄昏（夕阳金色光线）】
```

**错误示例：**
```
❌ 城市里的街道，晚上
❌ 办公室，白天
❌ 竹林
```

### 3. 人物标注规范

#### 首次出场
**格式：** `【角色类型 - 姓名（年龄，外貌特征）】`

**示例：**
```
【男主 - 林澈（22岁，白衬衫+黑框眼镜，眼神清冷）】
【女主 - 苏晚（20岁，红裙+长发披肩，笑容甜美）】
【反派 - 赵坤（35岁，西装+油头，嘴角带着冷笑）】
【配角 - 红发机车男（红色短发+皮夹克+机车头盔）】
```

#### 后续出场
**格式：** `【角色名（状态）】`

**示例：**
```
【林澈（皱眉）】
【苏晚（微笑）】
【赵坤（冷笑）】
```

#### 群像/背景标注
**格式：** `【角色（背景虚化，微动态）】`

**示例：**
```
【路人甲/乙（背景虚化，微动态）】
【员工A/B/C（群体动态，背景）】
```

## 四、动作描述详解

### 动作描述公式

**格式：**
```
【主体（情绪/状态）：动作描述（中动态：具体效果），细节描述（特写：具体效果）】
```

### 错误vs正确对比

| 错误写法 | 正确写法 |
|----------|----------|
| 林澈很生气，走过去质问对方 | 【林澈（咬牙，攥拳）：快步上前（中动态：脚步位移+手臂摆动），直视对方（特写：瞳孔收缩）】 |
| 女主很惊讶 | 【女主（瞪大双眼，微微后退）：（微动态：眼皮颤动+裙摆轻飘）】 |
| 他感到悲伤 | 【男主（眼眶泛红，嘴角下垂）：（无台词，微动态：手指轻颤）】 |
| 坏人得意地笑 | 【赵坤（奸笑，嘴角上扬）：（微动态：眼角皱纹抽动+手指敲击桌面）】 |

### 动作描述要求

1. **可执行**：动作需明确具体，制作团队可直接执行
2. **避免抽象**：不用"感到""觉得"等抽象词
3. **情绪外化**：通过表情/肢体呈现内心状态

## 五、台词规范详解

### 台词基本格式

**格式：** `【角色名（情绪，口型：微/中/大）：“台词内容”】`

**示例：**
```
【林澈（愤怒，口型：中）：“你为什么要这么做？！”】
【苏晚（惊讶，口型：大）：“什么？！这不可能！”】
【赵坤（冷笑，口型：微）：“……嗯。”】
```

### 口型分级

| 等级 | 字数 | 使用场景 | 标注 |
|------|------|----------|------|
| 微 | 单字/语气词 | 回应、语气词 | 口型：微 |
| 中 | 5字以内 | 短句对话 | 口型：中 |
| 大 | 6字以上 | 长句台词 | 口型：大（需标注"口型放大"） |

### 人设适配台词示例

| 人设类型 | 台词风格 | 示例 |
|----------|----------|------|
| 学霸角色 | 简洁，专业术语多 | "根据压强公式分析，这个结构不稳定。" |
| 活泼角色 | 带语气词，短句为主 | "太好啦！""真的吗？""好开心呀！" |
| 高冷角色 | 少台词，多单字/省略号 | "……""嗯""随便""不知道" |
| 奸角角色 | 阴阳怪气，带威胁 | "呵呵，你以为你能逃掉？" |
| 正直角色 | 直接，正气 | "我一定会查清楚真相！" |

### 口语化对照表

| 书面化（避免） | 口语化（使用） |
|----------------|----------------|
| 吾辈 | 我 |
| 甚是遗憾 | 太可惜了 |
| 汝 | 你 |
| 为何 | 为什么 |
| 何人 | 谁 |
| 此话怎讲 | 什么意思 |
| 告辞 | 我先走了 |
| 稍安勿躁 | 别急别急 |

### 节奏控制

| 要求 | 说明 |
|------|------|
| 单句字数 | 不超过10字 |
| 对话形式 | 一问一答，避免大段独白 |
| 独白限制 | 不超过30字 |

## 六、动态标注详解

### 三级动态体系

| 等级 | 标注 | 效果示例 | 成本 | 使用频率 |
|------|------|----------|------|----------|
| 微动态 | 【动・微】 | 头发轻飘/眼皮颤动/手指微动/镜头缓慢推拉 | 低 | 必用 |
| 中动态 | 【动・中】 | 肢体位移/物体小幅运动/镜头切换（溶解/切出） | 中 | 常用 |
| 强动态 | 【动・强】 | 打斗动作/爆炸特效/快速转场（闪白/震动） | 高 | 慎用（≤3处/集） |

### 动态标注位置
括号内标注，格式：「动态等级：具体效果」

### 动态分层原则

| 层级 | 动态等级 | 示例 |
|------|----------|------|
| 前景（主体） | 中/强 | 主角挥拳（强动态） |
| 中景（环境） | 微 | 树叶轻摇（微动态） |
| 背景 | 静态/虚化 | 建筑虚化（静态） |

**分层示例：**
```
【前景：男主挥拳（强动态）；中景：树叶轻摇（微动态）；背景：建筑虚化（静态）】
```

### 动态等级案例

**微动态案例：**
```
【林澈（沉思）：（无台词，微动态：手指轻敲桌面+眉头微皱）】
【苏晚（害羞）：（微动态：脸颊泛红+眼皮低垂+手指绕发丝）】
```

**中动态案例：**
```
【林澈（起身）：站起（中动态：椅子后移+身体直立），走向窗边（中动态：脚步位移）】
【苏晚（追赶）：小跑上前（中动态：裙摆飘动+脚步急促），拉住林澈手臂】
```

**强动态案例：**
```
【打斗场景】
【林澈 vs 赵坤】
【强动态：拳头挥出（镜头跟随手臂+震动特效）+ 赵坤后退踉跄（中动态：脚步踉跄）+ 茶杯摔碎（特写：碎片四溅+强动态：震动）】
```

### 强动态使用禁忌
- 单集不超过3处
- 避免多人同时强动态（如3人以上打斗→简化为「主角强动态+配角微动态」）

## 七、音效/字幕标注详解

### 格式
```
【音效：具体声音描述】
【字幕：具体内容】
```

### 音效标注示例
```
【音效：手机掉落声（清脆）】
【音效：脚步声由远及近】
【音效：玻璃破碎声（剧烈）】
【音效：风声（呼啸，持续）】
```

### 字幕标注示例
```
【字幕：警告！距离爆炸还有10秒】
【字幕：第3集 真相】
【字幕：一年前...】
```

### 音效使用规范
- 音效不超过台词量的30%
- 避免音效堆砌
- 重要警告用【字幕】标注

## 八、IP改编特殊要求

| 要素 | 要求 | 改编说明 |
|------|------|----------|
| 核心剧情 | 100%还原 | 关键对话、名场面不可删改 |
| 人设 | 服装/发型/性格不变 | 如需调整，必须标注「改编说明」 |
| 场景 | 标志性场景保留核心元素 | 如主角家、学校等 |
| 动态补充 | 原作静态画面补充合理动态 | 如小说"他笑了"→"嘴角上扬（微动态：脸颊肌肉抽动）" |

### IP改编案例
```
【原作：林浩天走到窗前，看着窗外的夜景，陷入了深深的回忆。】
【改编：】
【林浩天（眼神深邃）：走向落地窗（中动态：脚步缓慢），凝视窗外（特写：瞳孔倒映城市灯光），（无台词，微动态：手指轻触玻璃+呼出一口气）】
```

## 九、审核标准检查清单

| 维度 | 检查项 | 合格线 |
|------|--------|--------|
| 格式 | 场景头/人物标注/动作描述/台词/动态标注 | 100%符合规范 |
| 内容 | 敏感信息/人设逻辑 | 无敏感，人设自洽 |
| 动态 | 等级标注/强动态数量 | 标注清晰，≤3处/集 |
| 节奏 | 情绪拐点/动作亮点 | 每30秒有亮点 |
| 时长 | 单集字数 | 800-1200字（3-5分钟） |
| 落地性 | 动作/动态可执行性 | 均可落地 |

## 十、新人必看Tips

1. **沟通优先**：不确定的动态设计（如复杂打斗），先和制作团队确认「是否可实现」

2. **道具标注**：重要道具（如带密码的笔记本）需标注「特写+微动态（页面翻动）」

3. **修改顺序**：初稿完成后，按「格式→内容→动态→台词」顺序自查

4. **复用模板**：重复场景可复用动态模板（如走路动作→统一标注「中动态：标准步行循环」）
