# 设定GIT

首先让AI 初始化GIT 然后把你仓库和密钥发给他 让他做完就更新

# 探讨功能

## 二开

如果你想二开 就首先让AI阅读完整代码

## 首次开发

如果是首次开发 那么就开始和AI探讨 MVP（最小可实现）功能

主要是实现核心功能，后续其他内容慢慢扩展

# 设定规范

让AI在本地AGENTS.md设定规则

```
每次改动完，构建对应GIT COMMIT,COMMIT内容不要很详细， 如果有密钥 尝试上传GITHUB,并且检测仓库是否PUBLIC;如果是那么就模糊所有隐私数据，否则直接上传
每次改动后，必须编写或更新相应测试，并且在交付用户前，确保所有测试和验证全部通过

```

这里的内容就是AI自己会读并且遵守的 所以有什么新的加上去就可以

# 设计

确定内容后 让AI在本地 确定产品设计方案

```
整理一下这个产品的产品设计方案，不要太详细，把整体方向和主要功能梳理出来,放在docs文件夹里面
```

## 生成Demo

这个是很重要的 让AI 在本地通过html 生成一个 前端 模拟数据即可

```
写个前端demo,html单文件，数据是完全模拟的,我需要看看整体操作界面和操作流程是否合理
```

# 技术方案

```
在目录下有产品设计方案，首先读取，然后告诉我，什么技术栈实现比较合理，不要太过详细，先进行探讨
```

```
现在生成一个技术文档,放在docs文件夹里面
```
