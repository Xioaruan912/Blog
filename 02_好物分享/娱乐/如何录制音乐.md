# 如何录制音乐

这里就很简单的 得到伴奏 然后 录制

主要使用[reaper](https://www.reaper.fm/) 还有一个伴奏的分离[AI](https://github.com/boy1dr/SpleeterGui) 然后就是下载的资源站 https://music.gdstudio.xyz/

# 安装reaper

去官网下载即可 足够使用了

下面是汉化

https://club.reaget.com/t/topic/1960

下载好双击打开 即可跳转 记得存到reaper的目录去 删掉汉化就没了



# 下载音乐

直接打开资源站 下载即可

https://music.gdstudio.xyz/



# 分离伴奏

下载GUI程序 打开拖入即可分离

# Reaper使用方法



直接拖入伴奏 然后设置第二个轨道 当作录制

不要听到自己的声音 就按下这个按钮

![image-20260723231943144](https://raw.githubusercontent.com/Xioaruan912/pic/main/20260723231943162.png)

然后点击左边的红色开始监听

按Ctrl+R 进行录制 这样结束后就可以听到自己的了

如果要导出 就记得去渲染即可
