# 碳水渐降

如果是180cm 80 kg 那么就280g 碳水 140 蛋白质 55g脂肪 

**目的：** 在稳定饮食的基础上，视情况逐步降低碳水摄入。

| 营养素     | 每日摄入       |
| ---------- | -------------- |
| 碳水       | **250 g**      |
| 蛋白质     | **140 g**      |
| 脂肪       | **55 g**       |
| 估算总热量 | **2,055 kcal** |

如果一周体重稳定降低 0.5kg左右，就继续这样吃

如果一周体重不降低并且反而提升，降低 10-20g 碳水

**缺点：没有放纵，因为你每天都是正常吃饭 ，或者 俩周一次放纵，并且放纵只能一餐**

# 碳循环

如果你对自己的训练有信心，180cm  70kg左右的话就：

低碳： 100g 碳水 140g 蛋白质 50g脂肪

高碳： 300g 碳水 40g 蛋白质 不主动摄入脂肪【其中蛋白质是排除碳水的】

## 低碳摄入

| 营养素     | 每日摄入       |
| ---------- | -------------- |
| 碳水       | **100 g**      |
| 蛋白质     | **140 g**      |
| 脂肪       | **50 g**       |
| 估算总热量 | **1,410 kcal** |

## 高碳摄入

| 营养素           | 已确认目标 |
| ---------------- | ---------- |
| 碳水             | **300 g**  |
| 脂肪             | **20 g**   |
| 排除碳水的蛋白质 | **40 g**   |

可用使用 四低一高 或者 三低一高【如果你觉得自己消耗很大】

必要可以增加 练后有氧 推荐自行车机器 

30分钟 

阻力等级： LV4 

踏频： 约 60–65 RPM 

功率： 131–134 W

那么如果要我推荐 我推荐碳循环，因为碳水渐降的时间太长并且降低速度太慢，见效很慢，碳循环你使用两星期差不多就可以发现，但是这个是要基于你消耗足够大的情况下

并且碳循环你一个星期可以安排一次 放纵餐 我自己测试后 68 吃完 71 但是重新低碳2天 重新回到 69 

但是碳水渐降 我吃完后需要一整个星期才可以捡回原本
