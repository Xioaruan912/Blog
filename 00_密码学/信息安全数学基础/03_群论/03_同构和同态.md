# 映射

我们学习同态同构之前 先学习前置知识点 也就是映射，这也是我们从小学习到大的内容

一个集合A到另一个集合B的映射函数f 是对任意的 a in A，都有唯一确定的 b = f(a) 与之对应

其中 b 叫做 a在f的像 

a叫做原像

单射：如果对于任意的 a b in A 都有 f(a) != f(b) 那么就是单射

满射：如果对于任意的 b in B 都有 a in A 使得 f(a) = b 其中这里可以多个 a 对应一个b

一一映射：既满足满射又满足单射

# 变换

我们之前讨论的是 两个不同的集合，我们如果集合是相同的 

那么 映射 f 也叫做变换，也就是一个集合映射到自己的 叫做变换

我们把 f 也可以叫做 恒等映射、单位映射、恒等变换



那么我们如何从映射转化为 同态相关的呢 因为映射是元素相关的，元素不存在二元运算内容

所以下面我们讨论的是 群中元素 映射到另一个群中的关系，就是同态

# 同态和同构

代数系统 （A，.） 和 代数系统（B,*）如果存在一个映射f，把A中的元素映射到 B中，并且对于任意的ab in A 都有

f(a.b) = f(a) * f(b)

那么这个f 我们就叫做 同态映射 

同态映射 = 先运算再映射，和先映射再运算，结果一样 （这里理解非常重要）

如果这个同态映射还是一一映射，那么就叫做同构映射

同构就是可以完美的还原，既可以 A 映射到 B 又可以从 B 还原为 A

在G->G'的同态下满足下面的内容

1. G单位元e 的像 f(e) 是 G'的单位元e'

也就是 f(e) = e'

2. G中任意元素a的逆元a^-1的像是 f(a)的逆元

也就是 f(a^-1) = f(a)^-1

3. G在f下的像的集合 是 G'的子群，也叫做f的像子群

也就是 a in G ，f(a) 的集合是 G'的子群

# 同态映射的核

这个可以看作是一个非常有用的子群

f是G到G'的同态，对于任意的a' in G'

{a in G | f(a) = a'}

可能是空集 也可能是包含一个以上元素

这个集合叫做a'的完全反像

理解一下这个：

给你f : X->Y 

1. 我们正常是问 x 映射到哪里Y的哪里
2. 但是完全反像是说：给你Y中的一个集合B，X的哪些元素会被作用后进入B呢？

![image-20260906223331620](https://raw.githubusercontent.com/Xioaruan912/pic/main/20260906225840425.png)

特别的 如果这个元素是e' 的完全反像，就叫做f的核 记作 ker(f)

**把 G 里所有经过 f 之后变成单位元的元素全部找出来，这个集合就是 ker。**

完全反像说明的是 哪些元素映射到这个集合内

KER 说明的是 哪些元素 映射到单位元上
