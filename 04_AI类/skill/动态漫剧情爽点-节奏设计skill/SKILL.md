# 动态漫剧情节奏与爽点设计技能

## 核心能力

对用户提供的原始剧本进行**节奏把控**和**爽点设计**，让剧情更抓人、更有看点。

## 输入信息清单

优化前请确认以下信息：

| 信息 | 说明 | 必填 |
|------|------|------|
| 剧本名称 | 动态漫标题 | ✅ |
| 集数 | 第X集 | ✅ |
| 主要角色 | 角色名及简要人设 | ✅ |
| 本集场景 | 涉及的场景列表 | ✅ |
| 原始剧本内容 | 现有剧本或故事梗概 | ✅ |
| 目标时长 | 3-5分钟（默认） | 可选 |

## 核心公式

**节奏起伏 = 压抑/铺垫（慢）→ 爆发/反转（快）**

**无压抑则无爽感**

## 节奏把控公式（单集精准到秒）

| 时间段 | 节奏 | 内容要求 | 动态等级 |
|--------|------|----------|----------|
| 0-30s | 慢（铺） | 引入矛盾、建立人设 | 微动态 |
| 30-90s | 慢（抑） | 主角受挫/误解/困境 | 基础动态 |
| 90-120s | 快（爆） | 核心爽点爆发 | 强动态+特写 |
| 120-180s | 中（转） | 后续小爽点+伏笔 | 中度动态 |
| 总时长3-5min | - | 1个核心爽点+2-3个小爽点 | - |

**禁忌：**
- 连续120秒以上同节奏（慢节奏不超过90秒，快节奏不超过60秒）
- 无爽点平淡期超过60秒

## 爽点设计三大类型

### 1. 情绪释放型爽点（新手优先）

**核心逻辑：** 先压抑30-60秒，再释放

**公式：**
```
铺垫：让主角受委屈/被误解/陷困境
释放：通过反抗/自证/被认可释放情绪
动态：释放瞬间用「中→强动态升级」
```

**动态适配：** 主角委屈时的微动态（肩膀轻颤、攥拳、眼眶泛红）→ 翻盘时的强动态（挺直腰背、环境反应）

---

### 2. 反转打脸型爽点（高记忆点）

**核心逻辑：** 打破观众/主角的固有认知

**公式：**
```
铺垫：反派嚣张/他人轻视（20-30秒）
反转：隐藏实力/关键证据/反转设定
动态：反转瞬间用「强动态+特写」
```

**动态适配：** 反派推主角肩膀（中动态）→ 主角快速出手扣住反派手腕（强动态+特写：青筋凸起）

---

### 3. 高光时刻型爽点（系列剧必备）

**核心逻辑：** 主角展现超预期能力或高光行为

**公式：**
```
铺垫：核心冲突爆发，主角陷入绝境
高光：突破极限/隐藏技能/正义选择
动态：全程强动态+多镜头切换+字幕强化
```

**动态适配：** 火灾场景（强动态：火焰蔓延+烟雾）→ 主角灭火救援（强动态+特写：眼神坚定+脸上沾灰）

## 爽点设计避坑指南

| 错误 | 问题 | 修正 |
|------|------|------|
| 爽点无铺垫 | 主角突然开挂，无伏笔 | 前期加入伏笔道具/细节 |
| 爽点过载 | 单集强动态爽点>3处 | 核心爽点强动态，小爽点中动态 |
| 爽点与人设冲突 | 高冷角色突然搞笑 | 克制但炸裂：眼神杀+简洁台词+强动态 |
| 爽点无视觉化 | 只用台词说"赢了" | 用动态呈现：对方倒地+主角站立的画面 |

## 冲突驱动法（无冲突无节奏）

**优先选这3类冲突：**
- **肢体冲突**：适配强动态（打斗、追逐）
- **言语冲突**：适配中动态（争吵、打脸）
- **心理冲突**：适配微动态（纠结、伪装）

**冲突密度：** 每45秒至少1个小冲突，每集1个核心冲突

## 留白技巧（节奏"呼吸感"）

在强冲突/爽点后，留3-5秒"无台词+微动态"，让观众消化情绪

**案例：**
```
主角打脸反派后→
【反派（脸色铁青，愣住）：（无台词，口型：微）】
【微动态：反派嘴角抽搐 + 主角头发轻飘，镜头缓慢拉远】
【音效：短暂静音后，轻微风声】
```

## 低成本爽点设计技巧

无强动态也能做爽点：
- **台词打脸**：犀利台词反击
- **细节胜利**：道具/表情展现（如录音笔指示灯闪烁）
- **他人认可**：配角反应衬托

## 审核标准

输出后自动检查：
- [ ] 单集无平淡期超过60秒
- [ ] 快慢切换自然，每30秒有情绪波动
- [ ] 单集至少1个核心爽点（小爽点分布均匀）
- [ ] 爽点动态等级不超标
- [ ] 爽点与人设/剧情逻辑自洽
