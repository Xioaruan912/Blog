# 动态漫剧本详细写作技能

## 核心能力

对用户提供的原始剧本进行**超详细写作补充**，包括动作描述、动态标注、台词规范、场景细节等，输出专业级可执行的动态漫剧本。

## 输入信息清单

优化前请确认以下信息：

| 信息 | 说明 | 必填 |
|------|------|------|
| 剧本名称 | 动态漫标题 | ✅ |
| 集数 | 第X集 | ✅ |
| 主要角色 | 角色名及简要人设 | ✅ |
| 本集场景 | 涉及的场景列表 | ✅ |
| 原始剧本内容 | 现有剧本或故事梗概 | ✅ |
| 目标时长 | 3-5分钟（默认800-1200字） | 可选 |

## 核心原则（不可突破）

| 原则 | 说明 |
|------|------|
| 视觉优先 | 动态漫以「静态画面+有限动态」为核心，避免大段心理描写，需转化为表情/动作 |
| 节奏适配 | 每30秒需有「情绪拐点/动作亮点」，避免信息过载 |
| 成本可控 | 强动态（打斗/爆炸）单集不超过3处 |
| IP适配 | 改编类100%还原原作，原创类保持人设一致、世界观自洽 |

## 单集标准结构

| 模块 | 内容 | 位置 |
|------|------|------|
| 场景头 | 【景别-地点-时间+光线】 | 每场景开头 |
| 人物标注 | 【角色名（状态）：动作描述】 | 首次完整/后续精简 |
| 动作描述 | 主体+动作+动态等级 | 每分镜核心 |
| 台词 | 人物+情绪+口型适配 | 角色发言时 |
| 动态标注 | 微/中/强动态效果 | 括号内标注 |
| 音效/字幕 | 右上角【】包裹 | 需要时标注 |

## 场景头格式

```
【外景/内景 - 地点 - 时间（光线条件）】
```

**示例：**
- ✅ 正确：【外景 - 临江大道 - 深夜（路灯暖光）】
- ❌ 错误：城市里的街道，晚上

**光线条件标注：** 晨光/暗光/霓虹灯/月光/阳光斑驳等

## 人物标注规范

| 类型 | 格式 | 示例 |
|------|------|------|
| 首次出场 | 【角色 - 姓名（年龄，外貌特征）】 | 【男主 - 林澈（22岁，白衬衫+黑框眼镜，眼神清冷）】 |
| 后续出场 | 【角色名（状态）】 | 【林澈（皱眉）】 |
| 群像/背景 | 【角色（背景虚化，微动态）】 | 【路人甲/乙（背景虚化，微动态）】 |

## 动作描述公式

**格式：** 【主体（情绪/状态）：动作描述（中动态：具体效果），细节描述（特写：具体效果）】

**原则：**
- 动作需「可执行」，避免抽象描述
- 错误：「感到悲伤」→「正确：眼眶泛红，嘴角下垂」
- 错误：「很生气，走过去质问」→「正确：【林澈（咬牙，攥拳）：快步上前（中动态：脚步位移+手臂摆动），直视对方（特写：瞳孔收缩）】

## 台词规范

### 格式
```
【角色名（情绪，口型：微/中/大）：“台词内容”】
```

### 口型分级

| 等级 | 字数 | 标注 |
|------|------|------|
| 微 | 单字/语气词 | 口型：微（如"哦""嗯""啊"） |
| 中 | 短句5字以内 | 口型：中 |
| 大 | 长句6字以上 | 口型：大（需标注"口型放大"） |

### 人设适配原则

| 人设 | 台词特点 | 示例 |
|------|----------|------|
| 学霸角色 | 简洁，专业术语多 | "根据压强公式分析..." |
| 活泼角色 | 带语气词，短句为主 | "太好啦！""真的吗？" |
| 高冷角色 | 少台词，多单字/省略号 | "……""嗯""随便" |

### 节奏控制
- 单句台词不超过10字
- 两人对话需「一问一答」，避免大段独白
- 独白不超过30字

### 口语化原则
避免书面化表达：
- ❌「吾辈」→ ✅「我」
- ❌「甚是遗憾」→ ✅「太可惜了」
- ❌「汝」→ ✅「你」

## 动态标注规范

### 三级动态

| 等级 | 标注 | 效果 | 使用场景 |
|------|------|------|----------|
| 微动态 | 【动・微】 | 头发轻飘/眼皮颤动/手指微动/镜头缓慢推拉 | 低成本，必用 |
| 中动态 | 【动・中】 | 肢体位移/物体小幅运动/镜头切换（溶解/切出） | 常用 |
| 强动态 | 【动・强】 | 打斗动作/爆炸特效/快速转场（闪白/震动） | 慎用，单集≤3处 |

### 动态分层原则

| 层级 | 动态等级 | 示例 |
|------|----------|------|
| 前景 | 中/强 | 主角挥拳（强动态） |
| 中景 | 微 | 树叶轻摇（微动态） |
| 背景 | 静态/虚化 | 建筑虚化（静态） |

### 动态案例

```
【女主（惊）：后退半步（中动态：身体后仰+裙摆飘动），手机滑落（强动态：镜头跟随手机下坠，震动特效）】
```

## 音效/字幕标注

### 格式
```
【音效：具体声音】
【字幕：具体内容】
```

### 规范
- 音效不超过台词量的30%，避免堆砌
- 重要警告/提示用【字幕】标注

## IP改编特殊要求

| 要素 | 要求 |
|------|------|
| 核心剧情 | 100%还原（如关键对话、名场面） |
| 人设 | 服装/发型/性格不能修改 |
| 场景 | 标志性场景保留核心元素 |
| 动态补充 | 原作静态画面补充合理动态（如小说"他笑了"→剧本"嘴角上扬（微动态：脸颊肌肉抽动）"） |

## 审核标准

输出后自动检查：
- [ ] 格式100%符合规范（场景头/人物标注/动作描述/台词/动态标注）
- [ ] 无敏感信息（政治/暴力/色情）
- [ ] 人设逻辑自洽
- [ ] 动态等级标注清晰，强动态不超标（≤3处）
- [ ] 每30秒有情绪拐点/动作亮点
- [ ] 单集时长3-5分钟（800-1200字）
- [ ] 所有动作/动态均可落地执行
