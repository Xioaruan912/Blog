# 动态漫人物小传写作技能

## 核心能力

为用户提供的人物角色信息，创作**完整的动态漫人物小传**，包括基础信息、核心背景、性格行为逻辑、动态专属设定、剧情关联等模块。

## 输入信息清单

创建小传前请确认以下信息：

| 信息 | 说明 | 必填 |
|------|------|------|
| 角色姓名 | 正式名+别名 | ✅ |
| 年龄 | 数字 | ✅ |
| 外貌特征 | 核心视觉关键词（3-5个） | ✅ |
| 性格特点 | 性格关键词 | ✅ |
| 背景故事 | 人物前史/关键经历 | 可选 |
| 在剧中的定位 | 主角/配角/反派等 | ✅ |
| 核心道具 | 是否有专属道具 | 可选 |

## 核心原则（不可突破）

| 原则 | 说明 |
|------|------|
| 适配性 | 所有设定需服务于"动态呈现"和"音画同步" |
| 精简性 | 拒绝冗余背景，聚焦"影响角色行为的关键信息" |
| 落地性 | 视觉、动态、声音设定需明确可执行 |

## 小传核心模块（按优先级排序）

### 模块1：基础信息栏（快速定位角色）

| 项目 | 填写说明 | 示例 |
|------|----------|------|
| 姓名/别名 | 正式名+常用别名 | 林墨/墨哥（苏晚专属称呼） |
| 年龄/外貌 | 年龄+核心视觉关键词（3-5个），需明确"不可变特征" | 22岁/黑短发、工装外套、红围巾、左眉骨疤痕 |
| 核心标签 | 3个关键词（性格+功能+特质） | 冷静毒舌、武力担当、外冷内热 |
| 声音特质 | 音色+语速+语气关键词，需明确"情绪起伏范围" | 中低音、语速偏快（日常）/放缓（紧张时） |
| 核心道具 | 专属道具+功能+动态呈现方式 | 腰间匕首/切割+防身/紧张时摩挲刀柄 |

### 模块2：核心背景（动机来源）

**填写逻辑：「关键经历→性格形成→核心执念→行为动机」**

| 分类 | 填写要求 | 示例 |
|------|----------|------|
| 关键经历 | 筛选1-3件影响角色性格/行为的核心事件 | 师父为救他牺牲；独自闯荡遭遇背叛 |
| 核心执念 | 角色行动的核心目标 | 找到师父失踪真相+保护苏晚 |
| 行为动机 | 执念延伸的具体行为逻辑 | 拒绝信任陌生人；对线索极度敏感 |

### 模块3：性格与行为逻辑

**核心：「显性表现+隐性反差+行为触发点」**

| 分类 | 填写要求 | 示例 |
|------|----------|------|
| 显性性格 | 日常状态的性格表现，对应"可视觉化的动作/语气" | 说话毒舌；站姿挺拔；极少笑 |
| 隐性反差 | 特定场景下的性格反转，需明确"触发场景+动态变化" | 苏晚受伤时语速变慢、眉头紧锁 |
| 行为触发点 | 让角色"打破常规"的关键场景 | 有人诋毁师父→直接动手 |

### 模块4：动态漫专属设定（直接服务制作）

**核心：「动作+微动态+声音细节」**

| 分类 | 填写要求 | 示例 |
|------|----------|------|
| 核心动作习惯 | 1-2个标志性动作（贯穿全剧），需标注"动态参数" | 思考时摸红围巾尾端（速度缓慢，幅度≤1cm） |
| 微动态特征 | 呼吸、眼神、肢体细节 | 紧张时呼吸加快，眼神左右扫视 |
| 声音细节 | 语气变化、口头禅、音效适配 | 口头禅"别废话"；情绪激动时声音拔高 |

### 模块5：角色功能与剧情关联

| 分类 | 填写要求 | 示例 |
|------|----------|------|
| 团队定位 | 角色在主角团/故事中的功能 | 剧情推动者、武力输出、保护者 |
| 关系互动 | 与其他核心角色的互动模式 | 对苏晚→表面嫌弃实际保护 |
| 成长弧线 | 单季/全剧的性格/行为变化 | 从拒绝信任→接受陪伴→愿意牺牲 |

## 填写技巧（避坑指南）

### 必避误区

| ❌ 错误写法 | ✅ 正确写法 |
|------------|-------------|
| "性格温柔" | "说话时语速放缓，嘴角微扬" |
| "内向" | "说话时低头，语速慢，双手攥衣角（幅度1cm）" |
| 堆砌无关背景 | 筛选影响核心行为的1-3件关键事件 |
| "长发飘飘" | "短发+固定发饰（方便动态设计）" |

### 填写技巧

1. **可视觉化/可动态化**：所有设定需能转化为具体画面
2. **动态参数明确**：速度（如"0.5秒完成转头"）、幅度（如"手臂摆动≤30度"）、频率（如"1次/秒"）
3. **关联前序设定**：核心动作/声音特质需贯穿全剧保持一致
