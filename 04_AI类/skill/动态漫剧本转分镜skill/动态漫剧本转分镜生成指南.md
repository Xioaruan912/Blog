# 动态漫剧本转分镜生成指南.md

## 一、剧本基础信息栏（页首固定区域）

```
剧名：《》
集数：第__集
制作周期：____年____月____日
```

此区域位于每一页顶部，用于快速识别剧本信息。

## 二、核心设定前置（剧本正文前）

### 1. 角色设定（精简关键信息）

格式：`【角色名】角色描述`

示例：
```
【林墨】青年侦探，擅长观察细节，性格冷静
【苏晚】林墨的搭档，武力值高，直觉敏锐
【神秘师父】二人寻找的目标，行踪成谜
```

### 2. 场景设定（本期涉及场景）

格式：`【场景名】场景描述`

示例：
```
【古宅阁楼】阴暗潮湿，堆满旧物，阁楼深处有一扇紧闭的铁门
【古宅大厅】破旧的大厅，墙上挂满泛黄的画像
```

### 3. 世界观补充（单集关联设定）

关键规则格式：`关键规则：例 "......"`

前置剧情格式：`前置剧情：例 "......"`

示例：
```
关键规则：阁楼内的水晶会映照真实内心，说谎者会被水晶发出的光灼伤
前置剧情：林墨与苏晚因寻找失踪的师父进入阁楼，此前已遭遇3次幻象攻击
```

## 三、分镜脚本格式（每格分镜为独立单元）

### 标准分镜模板

```
【分镜序号】
场景：
时间：
人物：
镜头：
动作/画面描述：
台词/音效：
动态效果：
转场：
备注：
```

### 示例

```
【分镜01】
场景：古宅阁楼
时间：夜晚
人物：林墨、苏晚
镜头：全景
动作/画面描述：昏暗的阁楼内，月光从破损的窗户洒入，照亮漂浮的灰尘。两人手持手电筒谨慎前行。
台词/音效：
【林墨】这里的气息不对劲，小心。
【苏晚】嗯，这个阁楼比我想象的要大。
【环境】老旧木板嘎吱作响（持续）
【配乐】悬疑低弦乐（3s，渐强）
动态效果：动・基础（光影闪烁）
转场：（切）
备注：▲ 水晶位置需在后续分镜中逐步揭示

【分镜02】
场景：古宅阁楼（深处）
时间：夜晚
人物：林墨
镜头：近景
动作/画面描述：林墨突然停下，手电筒光照到角落的一面古老镜子。镜面微微发光。
台词/音效：
【林墨】（低声）这面镜子...好像有什么东西。
动态效果：动・中度（镜头缓缓推进）
转场：（淡入）
备注：
```

## 四、特殊标注规范

### 1. 动态效果分级

| 等级 | 标注 | 适用场景 | 示例 |
|------|------|----------|------|
| 基础动态 | 【动・基础】 | 画面元素轻微运动 | 呼吸起伏、光影闪烁、头发飘动 |
| 中度动态 | 【动・中度】 | 镜头运动+元素组合 | 推镜+人物行走、摇镜+物体移动 |
| 特效动态 | 【动・特效】 | 粒子效果、形变、场景转换 | 爆炸、幻象切换、魔法效果 |

### 2. 转场类型

| 类型 | 标注 | 效果 | 适用场景 |
|------|------|------|----------|
| 硬切 | （切） | 无过渡直接切换 | 快速节奏、同一场景不同角度 |
| 渐变 | （淡入）/（淡出） | 画面明暗过渡 | 章节开始/结束、时间跳转 |
| 模糊转场 | （虚入）/（虚出） | 画面模糊后清晰 | 回忆、梦境、意识流 |
| 特效转场 | （闪白）/（光斑转场） | 特殊视觉过渡 | 魔法生效、情绪爆发、强烈冲击 |

### 3. 音效/配乐区分

**环境音**：格式 `【环境】+ 描述 +（持续/时长）`
- 例：【环境】雨水滴落声（持续）
- 例：【环境】远处雷声（2s）

**动作音效**：格式 `【动作】+ 描述 +（次数）`
- 例：【动作】门轴吱呀声（1次）
- 例：【动作】脚步在碎石上行走

**配乐**：格式 `【配乐】+ 风格 +（时长，状态）`
- 例：【配乐】紧张弦乐（3s，渐强）
- 例：【配乐】神秘空灵音效（5s，持续）

**配音/台词**：格式 `【角色名】+ 台词`
- 例：【林墨】别碰那个水晶！
- 例：【旁白】夜色渐深，危机悄然逼近。

### 4. 字幕标注

| 要素 | 规范 |
|------|------|
| 位置 | 画面下沿1/5区域（默认居中） |
| 特殊位置 | 字幕・左 / 字幕・右 / 字幕・上 |
| 对话字幕样式 | 白色字体 + 黑色描边 |
| 旁白字幕样式 | 灰色字体 + 无描边 |
| 时长计算 | 字幕显示时长 = 台词朗读时长 + 0.5s |

## 五、格式排版要求

| 要素 | 要求 |
|------|------|
| 正文字体 | 宋体（小四） |
| 标题字体 | 黑体（二号） |
| 角色名/场景名 | 加粗 |
| 正文行距 | 1.5倍行距 |
| 分镜单元间隔 | 空1行 |
| 分镜序号 | 连续编号（01,02,03...），不可断号 |
| 页面设置 | A4纸，上下边距2.5cm，左右边距2cm |
| 页码 | 位于页脚居中 |
| 重要标注 | 用"▲"标注在备注栏，例：▲ 水晶发光效果需与配乐节奏同步 |

## 六、分镜写作检查清单

- [ ] 分镜序号连续（01,02,03...）
- [ ] 每个分镜包含：场景、时间、人物、镜头、动作描述、台词音效
- [ ] 动态效果标注【动・基础】/【动・中度】/【动・特效】
- [ ] 转场标注（切/淡入/淡出/虚入/虚出/闪白/光斑转场）
- [ ] 音效区分【环境】【动作】【配乐】
- [ ] 台词标注角色名，旁白标注【旁白】
- [ ] 备注中重要动态用"▲"标注
- [ ] 字幕位置、样式、时长符合规范
