## OTP的问题

这里为了引出下面内容 我们先说 OTP为什么无法应用

OTP具有非常高的安全性，但是他依赖于一次一密

- 密钥长度和加密Message长度一致
- 每次通信都要产生新的密钥

基于上面两点 所以OTP 无法实用

那么就引出下面的思考了

> 如何使用一个短的密钥，加密一个长的消息？

3. 但是由于是确定性算法，所以2^n 只能映射到2^ n上，也就是说会有2^l永远映射不到


这个很困难 但是我们可以转化为下面

```
有一个算法输出和均匀是不可区分的
```

### 攻击场景

我们需要理解一下这个定义的攻击场景

- 受害者通过 均匀采样的S 输入G
- S 是受害者采样的，类似密钥，敌手无法控制，所以子程序没有参数
- 敌手观察G的输出 用于判别 两个输出是否可区分
- 受害者每个 S 只是用一次

# 5.2. Do PRGs exist?

这里讨论 伪随机发生器PRG 真的存在吗

我们无法给出一个能够像 OTP 那样得到无条件安全性证明的 PRG

如果PRGs存在，那么我们可以解决P vs NP问题

## P vs NP问题

P：能够在多项式时间内解决的问题

NP：如果给出了一个候选答案，能够在多项式时间内验证答案是否正确的问题

P vs NP问题：如果一个问题的答案能够被快速验证，那么这个问题本身是否也能被快速解决

所以在这里我们无法证明PRGs的安全性，即使我们得到了PRGs一些有希望的算法，我们也无法知道到底是不是安全的

但是我们可以使用一些不轻浮的推测：

比如使用强间接证据

我们可以直接公开PGRs，让敌手进行攻击，只要没有敌手攻击成功，那么就是安全的

**也就是说 在当前密码学理论中，安全 PRG 的无条件存在性尚未得到证明**

PRGs只是我们学习到的众多原语中的第一个，这些原语都是满足P vs NP问题的，也就是说我们无法通过完全数学证明，不依靠任何假设去证明安全性

但是 我们依旧可以这样来假设，选出有希望的算法，然后进行推测

那么可证明安全是不是没有用了？其实不然：

**可证明安全性的一个重要基石，就是我们能够利用数学证明来减少需要依赖的安全性猜想数量**

## 可证明的安全性是指关于安全性的条件性声明

> If A is secure, then B, which uses A as a component, is also secure.

B不需要任何完全关于安全的推测，只要基于A是安全的，就可以减少一些数学证明

PRGs是我们学习到最简单的原语，但是也是无法使用数学无条件证明的

如果PRGs是安全的，我们可以构建对称密码方案

我们可以通过PRGs构建出PRF，PRF是安全的只要PRGs安全 

我们可以通过PRF构建对称加密方案，对称加密方案是安全的只要PRF是安全的

可以发现最终都是依赖于 PRG的安全问题

**其实这里说明一个内容 密码学都是从简单的内容转向辅助问题的**

![image-20261025111251967](https://raw.githubusercontent.com/Xioaruan912/pic/main/20261025111252007.png)

但是现实中其实我们是使用PRP去构造

这些内容都不需要知道 我们只要知道我们使用PRGs的安全可以构建出这么多内容
